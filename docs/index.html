Install

Four steps, one of them annoying.

Notarizing an app needs a paid Apple account, which this project does not have. So macOS blocks the first launch and you clear it yourself. The checksum and the full source are published so you never take the download on trust.

  1. Download, unzip, drag Argus into Applications.
  2. Clear the download flag on this one app:
    xattr -dr com.apple.quarantine /Applications/Argus.app
    Or open it once, then System Settings › Privacy & Security › Open Anyway. The old Control-click → Open shortcut stopped working in macOS 15.
  3. Open Argus. A shield appears in the menu bar. Nothing else happens until something changes.
  4. On your own Wi-Fi, choose Mark this network as Home so Argus announces devices that join it.
Trust, but verify

Build it yourself in ten seconds.

Four Swift files, no dependencies, no package manager. Everything Argus reads comes from public macOS tools you can run yourself.

shasum -a 256 ~/Downloads/Argus.zip

cd argus/app && ./build.sh && open Argus.app
