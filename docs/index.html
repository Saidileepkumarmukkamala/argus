What it says,
and when.

Six moments from an ordinary week. Each is one card, in the notch, with what to do about it. Amber needs a decision. Green is for your information. Nothing repeats, and networks you mark as home stay quiet.

Sixteen more it watches for

    Click the notch.
    Everything, on one board.

    Twenty-six checks with the value behind each one, so "Firewall" is never just a green dot, it's "On", and "Apps open to the network" names the process and the port.

    Amber means decide

    Something needs a choice from you: stealth mode off, a dev server reachable by the whole café. Each row names the setting to change.

    Green means known

    Not "safe", known. FileVault on, no custom root certificates, no one connected. The board is a statement of fact, not a grade.

    The shield keeps score

    The menu bar shield carries an amber dot while anything needs attention, and nothing otherwise. It is the only thing Argus shows when it has nothing to say.

    A strip,
    when you want one.

    Turn on Always-on stats in the menu and the notch keeps a thin readout of processor load, memory, network throughput and Wi-Fi signal. It yields to alerts and comes back when they close. Off by default.

    0.2%of one core at idle, measured over an hour with every signal running.
    58 MBflat. State is pruned on every save, so memory does not climb.
    0 callsArgus never contacts a server, including ours. There is no ours.
    0 entitlementsNothing privileged. No Full Disk Access, no kernel extension.

    What Argus
    cannot do.

    It is awareness, not protection. A security tool that oversells itself is worse than none, so this list is on the front page.

      Four steps,
      one of them annoying.

      Notarizing an app needs a paid Apple account this project does not have, so macOS blocks the first launch and you clear it yourself. The checksum and the whole source are published so you never take the download on trust.

      1. Download, unzip, drag Argus into Applications.
      2. Clear the download flag on this one app:
        xattr -dr com.apple.quarantine /Applications/Argus.app
        Or open it once, then System Settings › Privacy & Security › Open Anyway. The old Control-click → Open shortcut stopped working in macOS 15.
      3. Open Argus. A shield appears in the menu bar. Nothing else happens until something changes.
      4. On your own Wi-Fi, choose Mark this network as Home so Argus announces devices that join it.

      Build it yourself
      in ten seconds.

      Eight Swift files, no dependencies, no package manager. Everything Argus reads comes from public macOS tools you can run yourself.

      shasum -a 256 ~/Downloads/Argus.zip
# compare against the checksum on the release page

git clone https://github.com/Saidileepkumarmukkamala/argus
cd argus/app && ./build.sh && open Argus.app
