Know what changed.
From the notch.

Argus watches the network you are on and what your Mac exposes to it, then says in plain English the moment something changes. It is silent the rest of the time.

The black shape is the app, drawn at the size it really is on a 14-inch MacBook. It cycles through alerts Argus actually sends. The text beneath is the same card, set at reading size.

What it tells you

Each signal is detected on its own and explained in one card that says what to do about it. Amber needs a decision, green is for your information. Nothing repeats, and networks you mark as home stay quiet.

Everything about your Mac, on one board

Click the notch. Twenty-six checks, each green or amber, each naming the setting to change. The menu bar shield carries an amber dot while anything needs attention.

A live strip, when you want one

Turn on Always-on stats in the menu and the notch keeps a thin readout of processor load, memory in use and Wi-Fi throughput. It is off by default, and it costs about 0.2% of one core.

What Argus cannot do

It is awareness, not protection. A security tool that oversells itself is worse than none.

Four steps, one of them annoying

Notarizing an app needs a paid Apple account this project does not have, so macOS blocks the first launch and you clear it yourself. The checksum and the whole source are published so you never take the download on trust.

  1. Download, unzip, drag Argus into Applications.
  2. Clear the download flag on this one app:
    xattr -dr com.apple.quarantine /Applications/Argus.app
    Or open it once, then System Settings › Privacy & Security › Open Anyway. The old Control-click → Open shortcut stopped working in macOS 15.
  3. Open Argus. A shield appears in the menu bar. Nothing else happens until something changes.
  4. On your own Wi-Fi, choose Mark this network as Home so Argus announces devices that join it.

Build it yourself in ten seconds

Eight Swift files, no dependencies, no package manager. Everything Argus reads comes from public macOS tools you can run yourself.

shasum -a 256 ~/Downloads/Argus.zip
# compare against the checksum on the release page

git clone https://github.com/Saidileepkumarmukkamala/argus
cd argus/app && ./build.sh && open Argus.app
